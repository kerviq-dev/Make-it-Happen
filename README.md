# Make It Happen Events — Luxury Event Planning & Digital Platform

Welcome to the **Make It Happen Events** workspace.

This repository contains the complete production web application and design references for **Make It Happen Events**, a bespoke luxury event curation atelier based in London, UK.

---

## 📁 Repository Overview

* **[`make-it-happen-app/`](file:///d:/Make%20it%20Happen/make-it-happen-app)**: The active React 18 + Vite + Tailwind CSS + Three.js production web application. See [make-it-happen-app/README.md](file:///d:/Make%20it%20Happen/make-it-happen-app/README.md) for full application documentation.
* **`Reference/`**: Project reference documentation, brand assets, and design specifications.
* **`stitch_make_it_happen_digital_premiere/`**: Original design screens and high-fidelity prototypes.

---

## 🚀 Quickstart (Running the Web App)

To run the application locally:

```bash
cd make-it-happen-app
npm install
npm run dev
```

The application will be accessible at `http://localhost:5173/`.

For complete details on route architecture, design tokens, Three.js 3D scenes, and WhatsApp integration, refer to [`make-it-happen-app/README.md`](file:///d:/Make%20it%20Happen/make-it-happen-app/README.md).
